<p id="description">ACTQ Application is an application developed to help the association efficiently manage its members. It allows for tracking member information managing registrations and events while providing a simple and intuitive interface for both administrators and members.</p>

  
  
<h2>🧐 Features</h2>

Here're some of the project's best features:

*   Member Management: Add edit delete and view member profiles.
*   Subscription Payments: Manage and track membership payments. Members can pay their subscription fees directly through the app.
*   Administrator Dashboard: A simplified dashboard that offers a quick overview of member payments event participation and other important metrics.
*   Payment Integration: Seamlessly integrate with payment gateways to collect membership fees (Stripe PayPal etc.).
